# 柔软的余地 — 期末考试第二部分

**在线地址（可直接发给别人）：<https://xq1125.github.io/final-exam/>**
仓库：<https://github.com/xq1125/final-exam>

一个可交互的网站，用来呈现第 16 课期末考试（*Critical Writing and Reading in Arts*，湖北大学）
PPT 部分要求的三块内容：**① 作为艺术家的自我介绍 ② 简短作品集 ③ 从本课程学到了什么**，
并按「视觉设计」要求做成了一套柔和的、纸感的数字媒体风格。

| 考试要求 | 网站对应位置 |
| --- | --- |
| 1. 作为艺术家的自我介绍（概括 Artist Statement） | **01 — 以艺术家的身份介绍自己** |
| 2. 简短作品集 + 创作意图 | **02 — 简短作品集**（含**绘本翻页阅读**） |
| 3. 从本课程学到了什么 | **03 — 我真正学到的东西** |
| 视觉设计：引人入胜、别具一格 | 全站：纸感底纹、低饱和插画色板、编辑式排版、滚动动效 |
| 至少 3 张幻灯片 | 一键导出 A4 横向 PDF |

**默认语言是中文**。英文版保留在右上角的 `EN` 开关里 —— 考试要求用英文提交，
交之前点一下 `EN`，再点 `导出 PDF` 即可。

## 打开方式

**双击 `index.html`**，用 Chrome / Edge 打开即可，不需要服务器、不需要联网。

> ⚠️ 不要在某些"预览面板"里看（比如聊天窗口里的卡片预览）。那类预览只解析 HTML/CSS/JS，
> 不会去读同目录 `assets/` 里的图片，会显示成一堆空白和"第一册 第1页"这样的代替文字。
> 如果遇到这种情况，用下面这个**单文件版**，它在任何地方打开都能显示图片。

| 版本 | 文件 | 用途 |
| --- | --- | --- |
| 文件夹版 | `index.html` + `assets/` | **主版本**：图片全分辨率，页面最轻快，用来展示和导出 PDF |
| 单文件版 | `郑铠妤_期末考试_单文件版.html` | 图片全部内嵌（6 MB），发给别人、放预览窗口里都能正常显示，图片按 1600px 压缩 |

## 绘本翻页（第二部分的核心）

页面上半部分是**《我，哭了没关系》小X成长记系列**的翻页阅读器：

- **第一册 / 第二册 / 第三册** —— 各 9 张跨页
- **家长手册** —— 3 张跨页（原来 6 页，两页并排合成一张，和绘本一样宽）

每张跨页在中间对折显示：左页不动，**右页绕着书脊翻过去**，翻到背面是纸张的背面，
和真书一样。翻页方式：点两侧的 `‹` `›`、按键盘 `←` `→`、在书页上左右滑动，
或点底部缩略图直接跳页。系统开了"减少动态效果"时自动省掉翻页动画。

## 其他可以玩的地方

- **EN / 中文**：整站中英切换（会记住你的选择）。
- **01 自述卡片**：点击标题行可以展开。
- **02 筛选**：全部 / 插画 / 视觉研究 / 商业与 AIGC。
- **02 作品图片**：点击放大；打开后可用 ← → 翻页、Esc 关闭。
- **02 年龄滑轨（3–6）**：点选年龄，下方文案随之变化。
- **03 三个支柱**：点 Pathos / Logos / Ethos，看它们在作品里各自负责什么。
- **03 批评光谱**：拖动标记，或直接点名字（纯主观 → 狄德罗 → 波德莱尔与左拉 → 格林伯格 → 纯客观）。
- **03 之前 / 之后**：点击每一行翻面。

## 导出 PDF

点右上角 **导出 PDF**，在打印对话框里选「另存为 PDF」。
打印样式会自动排版成 A4 横向幻灯片；语言跟随当前界面语言。

提交时的命名请按考试要求，例如：

```
069_郑铠妤_Final Exam.pdf
```

文件夹里已经放了两份现成的：

- `069_郑铠妤_Final Exam.pdf` —— 英文版（**这份用于提交**）
- `069_郑铠妤_Final Exam（中文）.pdf` —— 中文版（自己核对用）

## 换图 / 改文字

- **换绘本页**：把 `assets/book/` 里的同名文件替换即可（建议宽度 2400px，JPEG）。
  页数如果变了，改 `app.js` 里 `BOOKS` 的 `n`（第一册 → `b1`，以此类推），
  再重新生成 `th/` 里的缩略图。
- **换其他作品图**：改 `index.html` 里的 `src`；若长宽比不同，同步改
  `styles.css` 里对应的 `.shot.r-cover` / `.shot.r-ages` / `.shot.wide`，否则会被裁切。
- **改文字**：`index.html` 里每段都是成对的
  `<span lang="en">English</span><span lang="zh">中文</span>`，改对应那一半就行。
- 改完想重新出 PDF：重新点一次「导出 PDF」。
